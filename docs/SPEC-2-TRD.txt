4. LOCAL AGENT
The Local Agent is a native/desktop process installed on the user's PC.

Recommended:
- Rust, Go, or Node.js for the agent core.
- A signed installer.
- Local encrypted configuration.
- Secure outbound connection to the backend.
- No inbound public port by default.

Agent lifecycle:
START → LOAD CONFIG → AUTHENTICATE → CONNECT → HEARTBEAT → RECEIVE TASK → VALIDATE → EXECUTE TOOL → STREAM RESULT → COMPLETE/FAIL → IDLE

5. AGENT CONNECTION
Prefer outbound WebSocket connection.

Requirements:
- TLS.
- Agent identity.
- Short-lived access token.
- Refresh/re-authentication.
- Heartbeat.
- Reconnect with exponential backoff.
- Server-side revocation.
- Device/session tracking.

8. COMMAND SECURITY
Never blindly execute arbitrary AI-generated shell commands.

Use:
- Command parser.
- Allowlist/denylist.
- Working-directory restriction.
- Environment filtering.
- Timeout.
- CPU/memory limits where supported.
- Process tree tracking.
- Kill capability.
- Approval for privileged/dangerous operations.

9. FILE SECURITY
- Agent receives an allowed workspace root.
- Canonicalize paths.
- Block path traversal.
- Reject access outside workspace unless explicitly permitted.
- Protect .env, SSH keys, browser profiles and credential stores.
- Use separate permissions for read/write/delete.

10. BROWSER SECURITY
- Domain allowlist.
- Separate browser profile.
- No automatic access to existing personal browser sessions.
- Cookie/credential isolation.
- Block downloads/execution unless approved.
- Detect prompt injection in page content.

11. COMPUTER CONTROL SECURITY
- Explicit enable/disable.
- Visible session indicator.
- Screenshot privacy controls.
- Emergency stop hotkey/control.
- Restrict applications/windows where possible.
- Log every action.

12. AI PROVIDER ABSTRACTION
Create a provider interface:
generate()
stream()
countTokens()
healthCheck()
modelMetadata()

Providers can be swapped without changing the agent/tool layer.

API keys remain server-side. The browser and Local Agent should not receive provider secrets unless there is a deliberate, documented architecture requiring it.
